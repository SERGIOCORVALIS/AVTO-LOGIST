## 🔑 Runtime license key

API / tg-gateway / voice-gateway enforce a technical license gate:

1. First start records install time in `data/license.state.json`
2. **180 days** later the process **refuses to start** without `LICENSE_KEY`
3. Set a signed key in `.env`: `LICENSE_KEY=ALO1....`
4. Author issues keys with: `node scripts/issue-license.mjs --days 180`
5. After another 180 days of activation → request a **new** key

Optional: `LICENSE_ENFORCE=true` to require the key immediately (no grace).
