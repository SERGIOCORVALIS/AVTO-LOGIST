# Стиль RFQ к поставщикам (из архива переписки)

Запрос ставки: маршрут, груз, вес/объём/места, готовность, нужные услуги.
Без данных клиента (ИНН, телефон, точный завод без необходимости). Одна тема — один запрос. Указывай Ref сделки, если есть.

## Примеры тона

### Пример 1
Тема: Запрос ставки Новосибирск — Владивосток
Добрый день! Прошу ставку: Новосибирск → Владивосток, контейнер 40′, груз генеральный ~12 т / 28 м³, готовность на следующей неделе. Нужны срок и цена с/без НДС. Ref: укажите в ответе.

### Пример 2
Тема: RFQ жд+море Бердск — Корсаков
Добрый день! Запрос ставки ПСЖВС (жд+море): погрузка Бердск/Новосибирск → Корсаков, 40′HC. Вес уточню отдельно при необходимости. Прошу ставку и транзитное время. Ref в теме/теле письма.

### Пример 3
Тема: Ставка сборка Новосибирск — Москва
Добрый день! Нужна ставка сборной: Новосибирск → Москва, 1–2 места, ~800 кг / 3 м³, забор с адреса. Срок и стоимость с НДС. Спасибо.

### Пример 4
Тема: Уточнение по платформе
Добрый день! По ранее запрошенному маршруту: подтвердите возможность платформы/вагона, ставку и срок подачи. Груз не опасный. Ответ с Ref сделки.

### Пример 5
Тема: Повторный запрос ставки
Добрый день! Напоминаю запрос ставки по маршруту (см. Ref). Нужны актуальная цена и срок — предыдущая котировка истекла. Заранее спасибо.
